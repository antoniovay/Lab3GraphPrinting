# Lab3GraphPrinting

## 1. Постановка задачи

Цель работы - разработать приложение для построения и печати графиков на основе входных данных, загружаемых из файлов различных форматов.

В рамках работы необходимо:
- реализовать графический интерфейс пользователя;
- обеспечить загрузку данных из файлов JSON и SQLite;
- реализовать поддержку нескольких типов графиков;
- обеспечить возможность изменения визуального оформления графиков;
- реализовать экспорт графика в PDF-файл;
- использовать архитектуру MVC;
- реализовать внедрение зависимостей с помощью IoC-контейнера.

## 2. Предлагаемое решение

Для решения поставленной задачи была разработана система визуализации данных на базе Qt Framework.

### Архитектура приложения

В качестве архитектурного решения используется шаблон MVC (Model-View-Controller).

### Model

Модель представлена классом `DataModel`.

Назначение:

- хранение данных графика;
- уведомление остальных компонентов об изменении данных.

Основная структура данных:
```cpp
struct GraphData {
    qint64 xAxis;
    double yAxis;
};
```

### View

Представление реализовано классом `ApplicationWindow`.

Функции:

- отображение файловой системы;
- отображение графиков;
- выбор типа графика;
- переключение цветного и черно-белого режимов;
- сохранение графика в PDF.

### Controller

Контроллер реализован классом `MainController`.

Функции:

- обработка выбора файла;
- выбор необходимого парсера;
- получение данных;
- обновление модели;
- инициирование построения графика.

### Внедрение зависимостей

Для уменьшения связанности компонентов используется IoC-контейнер:
`IOCContainer`
Контейнер позволяет динамически регистрировать и получать объекты через интерфейсы.

Примеры внедряемых зависимостей:

- `IParser`
- `IChartCreator`

Преимущества подхода:

- снижение связанности модулей;
- возможность замены реализаций без изменения клиентского кода;
- расширяемость системы.

### Поддержка нескольких форматов данных

Для работы с различными источниками данных реализован интерфейс:
`IParser`

Конкретные реализации:

- `JsonParser`
- `SqlLiteParser`

Парсер выбирается автоматически в зависимости от расширения файла.

### Поддержка нескольких типов графиков

Создание графиков реализовано через интерфейс:
`IChartCreator`

Реализованы следующие типы:

- линейный график (Line Chart);
- площадной график (Area Chart);
- сглаженный график (Spline Chart);
- точечный график (Scatter Chart).

Каждый тип графика реализован отдельным классом.

### Используемые шаблоны проектирования

#### MVC

Разделяет приложение на:

- модель данных;
- представление;
- контроллер.

Преимущества:

- упрощение сопровождения;
- независимость пользовательского интерфейса от бизнес-логики.

#### Factory Method

Используется для создания различных типов графиков.
Позволяет добавлять новые типы графиков без изменения существующего кода.

#### Dependency Injection

Реализован через IoC-контейнер.
Позволяет работать через абстракции вместо конкретных реализаций.

## 3. Коды программ

Проект состоит из следующих основных модулей.

| Модуль | Назначение |
| --- | --- |
| ApplicationWindow | Пользовательский интерфейс |
| MainController | Управление приложением |
| DataModel | Хранение данных |
| JsonParser | Обработка JSON-файлов |
| SqlLiteParser | Обработка SQLite-файлов |
| GraphDataExtracter | Преобразование строк дат |
| IOCContainer | Внедрение зависимостей |
| AbstractChartCreator | Базовая логика построения графиков |
| LineChartCreator | Линейный график |
| AreaChartCreator | Площадной график |
| SplineChartCreator | Сглаженный график |
| ScatterChartCreator | Точечный график |

Особенностью проекта является использование интерфейсов, что позволяет расширять функциональность без изменения существующей архитектуры.

## 4. Инструкция пользователя

### Запуск программы

После запуска открывается главное окно приложения.

### Выбор каталога

Нажать кнопку: «`Выбрать путь`»
После выбора каталога в таблице отображаются доступные файлы.

### Загрузка данных

Пользователь выбирает файл:

- `.json`
- `.sqlite`

После выбора данные автоматически загружаются и отображаются в виде графика.

### Выбор типа графика

В выпадающем списке доступны:

- Line Chart;
- Area Chart;
- Spline Chart;
- Scatter Chart.

После выбора график перестраивается автоматически.

### Переключение цветового режима

Флажок «`Ч/Б`» включает высококонтрастное отображение графика.

### Сохранение графика

Нажать кнопку: «`Печать графика`»
Выбрать путь сохранения PDF-файла.
После подтверждения график сохраняется в формате PDF.
